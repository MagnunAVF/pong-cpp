# Pong Cpp

A classic two-paddle Pong game in C++17 using SDL2.

## Prerequisites

- CMake 3.16+
- A C++17 compiler (e.g. AppleClang/Clang, GCC)
- SDL2

On macOS, install SDL2 via Homebrew:

```sh
brew install sdl2
```

## Build

```sh
cmake -S . -B build
cmake --build build
```

## Run

```sh
./build/pong
```
